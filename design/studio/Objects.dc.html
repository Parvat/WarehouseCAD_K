ZonesOne calm family: same lightness, different hue. Icon and name top-left, size bottom-right. Racks never go inside. Edges act as walls, so man doors snap onto any zone edge (Office and Washroom shown).
StructureWalls are solid at true thickness. Doors are gaps in the wall with their width. Columns are solid squares.
RulesApplies to every object on the plan and in the PDF
One drawing at every zoom. Every object is drawn one way, at true size, and only scales. Selected = 2px green outline + square handles, for every object type. Problem = red dashed edge (+ hatch on areas). Never a red fill. Placing = half-opacity with a dashed edge while it follows the mouse. Locked = small lock in the top-right corner; no handles when selected. Labels = name in the object's darker tone, numbers in the drawing number style.
Library itemsEach item shows a small picture of exactly how it looks on the plan, in the plan colours. What you pick is what you get. Simple line icons stay only for the rail categories and buttons.
